# Workspace & Development Directives

## 🇬🇧 Communication & Language Policy (Mandatory)

1. **Default Assistant Response Language (Strictly English) :**
   - The assistant MUST ALWAYS respond in **English** by default for all explanations, code, technical discussions, and conversational replies, regardless of the language used by the user in prompts (e.g. French), unless the user explicitly requests otherwise for a specific response.
   - This maximizes token efficiency (~30% token savings), latency reduction, and international standard alignment.

2. **Developer Documentation Standard :**
   - All `README.md`, `CLAUDE.md`, `ARCHITECTURE.md`, `API.md`, system design docs, and walkthroughs MUST be written in **English**.

3. **Source Code & Comments :**
   - Code comments, docstrings, function signatures, variables, and database identifiers MUST follow standard English conventions.

4. **Git & Version Control :**
   - Commit messages, branch names, PR descriptions, and release notes MUST be in **English**.
